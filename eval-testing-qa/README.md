# Testing & QA Skills Project

This repository evaluates skills focused on software testing, TDD, end-to-end browser automation, and property verification.

## Installed Skills
* `.agents/skills/tdd-vitest-jest/`: Red-Green-Refactor, mock isolation, deterministic fake timers, and branch coverage.
* `.agents/skills/playwright-e2e/`: User-centric locators, auto-waiting, Page Object Models, and accessibility assertions.
* `.agents/skills/mutation-property-testing/`: Invariant testing via Fast-Check and mutation resilience testing.
