# Security & Vulnerability Audit Skills Project

This repository evaluates skills focused on application security, authentication, and AI safety guardrails.

## Installed Skills
* `.agents/skills/owasp-secure-coding/`: Hardening against OWASP Top 10 vulnerabilities (SQLi, IDOR, XSS, CSRF).
* `.agents/skills/auth-tokens-guard/`: JWT rotation, HttpOnly cookies, password hashing, and RBAC middleware.
* `.agents/skills/agent-prompt-defense/`: Indirect prompt injection fencing and safe tool invocation boundaries.
