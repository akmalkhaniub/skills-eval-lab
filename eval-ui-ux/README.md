# UI/UX Skills Evaluation Project

This repository evaluates and compares leading UI/UX skills for AI coding agents.

## Installed Skills
* `.agents/skills/plugin87-ux-ui/`: DTCG Design tokens, WCAG 2.2 AA-AAA compliance, multi-theme architecture.
* `.agents/skills/nextlevel-ui-ux-promax/`: Visual hierarchy, micro-interactions, responsive constraints, motion curves.
* `.agents/skills/jakubkrehel-accessibility/`: Keyboard navigation, screen reader ARIA compliance, contrast testing.
