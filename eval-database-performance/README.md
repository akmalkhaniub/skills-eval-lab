# Database & Systems Performance Project

This repository evaluates skills focused on database design, zero-downtime migrations, query indexing, and Redis caching.

## Installed Skills
* `.agents/skills/db-schema-migrations/`: The expand-contract pattern, safe backfills, and concurrent indexing.
* `.agents/skills/query-optimization-indexing/`: Composite indexes, EXPLAIN plan analysis, and N+1 elimination.
* `.agents/skills/cache-redis-patterns/`: Cache-Aside, TTL jitter, mutex locks, and key namespacing.
